# 프레임 데이터

> `scripts/spritegen/frame_data.py`가 기술 데이터에서 자동으로 만든 표입니다. 손으로 고치지 마세요.
> 숫자는 프레임(1/60초). **발생** = 판정이 처음 나오는 프레임, **빈틈** = 판정이 끝난 뒤 다시 움직일 수 있을 때까지.
> **가드 시 / 맞을 시** = 상대보다 몇 프레임 먼저 움직이는지 (+ 유리, − 불리). 연습 모드 화면 위의 '유불리'로 실제 값을 볼 수 있습니다.
