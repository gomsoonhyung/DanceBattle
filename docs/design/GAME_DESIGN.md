## 1. 격투 게임 기본 시스템

### 1-1. 입력 표기

격투 게임은 방향을 **숫자 키패드 모양**으로 적는다. 캐릭터가 오른쪽을 볼 때 기준이며, 왼쪽을 보면 좌우가 뒤집힌다.

```
7 8 9      ↖ ↑ ↗
4 5 6  =   ← · →      5 = 아무것도 안 누름
1 2 3      ↙ ↓ ↘
```

| 버튼     | P1  | P2  | 게임패드 |
| -------- | --- | --- | -------- |
| 약P (LP) | F   | K   | X        |
| 강P (HP) | G   | L   | Y        |
| 약K (LK) | V   | ,   | A        |
| 강K (HK) | B   | .   | B        |

예: `6HP` = 앞 + 강P, `236P` = ↓↘→ + 아무 P (흔히 "파동권 커맨드"), `623P` = →↓↘ + P ("승룡권 커맨드").

### 1-2. 움직임

| 동작        | 입력               | 설명                                                                    | 상태    |
| ----------- | ------------------ | ----------------------------------------------------------------------- | ------- |
| 걷기        | 6 / 4              | 앞·뒤로 걷는다. 뒤로 걸으면 자동으로 가드 자세                          | ✅ 있음 |
| 앉기        | 1·2·3              | 키가 낮아져 높은 공격을 피한다                                          | ✅ 있음 |
| 점프        | 7·8·9              | 4프레임 준비 후 뜬다. 공중 공격 1회                                     | ✅ 있음 |
| **앞 대시** | 6 6 (빠르게 두 번) | 짧은 거리를 순식간에 달려 들어간다. 캐릭터마다 거리·속도가 다르다       | 🆕      |
| **백대시**  | 4 4                | 뒤로 뛴다. **처음 몇 프레임은 무적**이라 상대의 압박을 빠져나갈 때 쓴다 | 🆕      |

### 1-3. 공격의 종류

| 종류                       | 입력                              | 설명                                                                | 상태             |
| -------------------------- | --------------------------------- | ------------------------------------------------------------------- | ---------------- |
| 일반기                     | 버튼 / 앉아서 버튼 / 점프 중 버튼 | 캐릭터마다 4 × 3 = 12개 (점프는 약·강 2개)                          | ✅ 있음          |
| **특수기** (커맨드 일반기) | 방향 + 버튼 (예: 6HP)             | 일반기의 변형. 중단기, 앞으로 나가는 기술, 원거리 견제 등 각자 특색 | 🆕               |
| 필살기                     | 커맨드 + 버튼 (236P 등)           | 캐릭터의 대표 춤. 4~5개                                             | ✅ 있음 → 재설계 |
| 초필살기                   | 236236P 또는 강P+강K (게이지 MAX) | 화면이 멈추며 발동하는 대형 연속기                                  | ✅ 있음          |
| **잡기**                   | 약P+약K (상대에게 붙어서)         | 가드할 수 없는 근접기. 넘어뜨린다                                   | 🆕               |

### 1-4. 공격 높이와 가드

| 높이     | 막는 법                            | 예                               | 코드       |
| -------- | ---------------------------------- | -------------------------------- | ---------- |
| **상단** | 서서 가드·앉아 가드 둘 다          | 대부분의 서서 공격, 장풍         | `mid`      |
| **중단** | **서서** 가드만 (앉아 있으면 맞음) | 점프 공격, 내려찍기, 특수기 일부 | `overhead` |
| **하단** | **앉아** 가드만 (서 있으면 맞음)   | 앉아 킥, 슬라이딩                | `low`      |
| 잡기     | 막을 수 없음 → **잡기 풀기**로만   | 잡기                             | `throw` 🆕 |

- **가드**: 상대 반대쪽(4)을 누르면 서서 가드, 1을 누르면 앉아 가드. 막아도 **깎임 데미지**(chip)가 조금 들어가는 기술이 있다 (필살기·초필살기).
- **가드 경직**: 막은 쪽도 잠깐 못 움직인다. 공격한 쪽이 먼저 움직일 수 있으면 "유리", 늦으면 "불리".
- **높은 공격은 앉으면 피해진다**: 판정이 높은 공격(점프 장풍 등)은 앉은 상대의 머리 위로 지나간다.

**가위바위보 구조** (격투 게임의 핵심 심리전)

```
공격  ──이김──▶  잡기 (잡으려고 다가온 상대를 때린다)
잡기  ──이김──▶  가드 (가드를 굳힌 상대를 잡는다)
가드  ──이김──▶  공격 (막고 반격한다)
```

여기에 **중단/하단 섞기**(서서 막을지 앉아 막을지 고르게 만들기)가 더해진다.

### 1-5. 잡기 🆕

| 항목          | 값                                                                            |
| ------------- | ----------------------------------------------------------------------------- |
| 입력          | 약P + 약K 동시 (3프레임 안)                                                   |
| 사거리        | 몸 앞 70 (붙어 있어야 함)                                                     |
| 조건          | 상대가 땅에 있고, 맞거나 막는 중(경직)이 아님                                 |
| 발생          | 5프레임. 헛잡으면 큰 빈틈 (전체 30프레임)                                     |
| 결과          | 120 데미지, 넘어뜨림. 앞으로 던지거나 (6 + 약P+약K) 뒤로 던진다 (4 + 약P+약K) |
| **잡기 풀기** | 잡힌 쪽이 7프레임 안에 약P+약K → 둘 다 튕겨 나오고 데미지 없음 ("TECH!")      |

춤 연출: 잡기는 상대와 **함께 추는 짧은 파트너 동작**이다. (크럼프는 밀쳐 내기, 왁킹은 팔을 감아 돌리기, 하우스는 다리 걸기 등)

### 1-6. 콤보

콤보는 상대가 경직에서 풀리기 전에 다음 공격을 맞히는 것이다. 이 게임에는 네 가지 이음 방법이 있다.

| 방법            | 설명                                                                         | 예                                      | 상태                 |
| --------------- | ---------------------------------------------------------------------------- | --------------------------------------- | -------------------- |
| **체인**        | 정해진 일반기끼리는 맞자마자 다음 버튼으로 이어진다                          | 약P → 약P → 앉아 약K                    | ✅                   |
| **캔슬**        | 일반기가 맞은(또는 막힌) 순간 필살기 커맨드를 넣으면 동작을 끊고 바로 필살기 | 앉아 강P → 236P                         | ✅                   |
| **슈퍼 캔슬**   | 필살기 → 초필살기                                                            | 236P → 236236P                          | ✅                   |
| **연결 (링크)** | 경직이 끝나기 전에 다음 기술이 나오면 그냥 이어진다 (타이밍 필요)            | 강P (유리 4프레임) → 약P (발생 4프레임) | ✅ (프레임 데이터로) |
| **공중 콤보**   | 띄운 상대를 다시 때린다. 최대 4번까지                                        | 대공기 → 점프 공격                      | ✅                   |

- **콤보 보정**: 맞은 횟수가 늘수록 데미지가 10%씩 줄어든다 (최소 30%). 긴 콤보가 너무 세지 않게.
- **기본 콤보 공식** (모든 캐릭터에 통하도록 만든다):
  - `약 → 약 → 필살기` (빠르고 쉬움)
  - `점프 강공격 → 앉아 강P → 필살기` (점프로 들어갈 때)
  - `하단 약K → 약P → 필살기` (하단에서 시작)
  - `필살기 → 초필살기` (게이지가 있을 때)

### 1-7. 카운터 히트 🆕

상대가 **공격을 내미는 중(발생~지속)** 에 때리면 **카운터 히트**.

- 데미지 +20%, 경직 +4프레임 → 평소엔 안 이어지던 콤보가 이어진다
- 강공격 카운터는 상대를 살짝 띄운다
- 화면에 "COUNTER!" 표시와 노란 이펙트

목적: 상대가 함부로 버튼을 누르지 못하게 하는 위험 요소.

## 2. 춤이 공격이 되는 규칙

일반 격투 게임은 주먹·발이 상대를 향하지만, 춤은 **상대를 보지 않는 동작**이 많다. 다음 규칙으로 바꾼다.

| 춤 동작의 모양                                        | 공격으로 만드는 법                                      | 예                                              |
| ----------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------- |
| 팔다리가 상대 쪽으로 뻗음                             | **그대로 근접 타격**                                    | 락킹 포인트, 크럼프 잽                          |
| 제자리에서 몸을 쓰는 동작 (웨이브, 체스트 팝, 스톰프) | **몸에서 퍼지는 파동 = 장풍 / 주변 충격파**             | 팝핑 웨이브 → 장풍, 크럼프 스톰프 → 바닥 충격파 |
| 크게 휘두르는 동작 (휩, 헤어 플립, 윈드밀)            | **과장된 리치**: 궤적 끝까지 판정. 팔·머리카락보다 길게 | 왁킹 휩, 걸스힙합 헤어 휩                       |
| 소품을 쓰는 춤                                        | **도구**: 던지거나 휘두른다                             | 락킹 모자 던지기                                |
| 회전·바닥 동작                                        | **앞뒤 동시 판정 + 낮은 자세**                          | 비보이 윈드밀                                   |
| 포즈·프리즈 (멈추는 동작)                             | **게이지 충전 / 반격 자세**                             | 왁킹 포즈, 비보이 프리즈                        |

- 이펙트로 판정을 보여 준다: 휩의 궤적, 팝의 전기, 스톰프의 충격파가 **판정이 있는 곳에만** 그려진다. 보이는 대로 맞는다.
- 리듬 시스템은 아직 넣지 않는다 (나중 과제).

### 3-0-1. 일반기 차별화 기준

원래 8명의 일반기 수치가 거의 같았다. 유형에 따라 다음과 같이 바꿨다 (`src/characters/builders.ts`의 `tune`, 각 캐릭터 `index.ts`).
크럼프는 원래부터 느리고 강하게 만들어져 있어서 조금만 더 했다.

| 왁킹     | ±0         | **+30%** (휩) | −20%   | 하단(앉아 약K·강K)은 데미지 ×0.6. 하단 필살기 없음 |
| 힙합     | ±0         | ±0            | ±0     | 기준                                               |
| 걸스힙합 | −1f        | ±0            | −5%    | 6HK 힐 드롭이 중단                                 |
| 락킹     | −1f        | +20%          | −20%   | 약P 연타가 빠름                                    |
| 하우스   | −1f        | −10%          | ±0     | 하단 3개 (앉아 약K·강K + 3LK), 앉아 킥 데미지 +20% |

| 비보이   | ±0         | ±0            | ±0     | 3HK·윈드밀이 앞뒤 회전 판정                        |

### 3-1. 크럼프 KRUMPER — 돌진·파워

> 짧고 느리지만 묵직하다. **아머로 맞으면서 밀고 들어가** 한 번 잡으면 크게 뺏는다.

| 항목               | 값                                               |
| ------------------ | ------------------------------------------------ |
| 체력 / 걷기 / 대시 | 1150 / 2.5 (가장 느림) / 짧고 묵직한 스톰프 대시 |
| 잡기               | **체스트 범프**: 가슴으로 밀쳐 날린다            |

| 기술           | 입력    | 춤 → 공격                                     | 성질                            |
| -------------- | ------- | --------------------------------------------- | ------------------------------- |
