# DANCE BATTLE

[![CI](https://github.com/gomsoonhyung/DanceBattle/actions/workflows/ci.yml/badge.svg)](https://github.com/gomsoonhyung/DanceBattle/actions/workflows/ci.yml)

춤 동작으로 싸우는 2D 대전 격투 게임입니다. 왁킹, 크럼프, 힙합, 걸스힙합, 락킹, 하우스, 팝핑, 브레이킹 8개 장르의 댄서가 각 장르의 동작을 기술로 써서 싸웁니다.
TypeScript + Vite + Canvas 2D로 만들었습니다. 캐릭터는 지금은 코드로 그린 그림이고, 격투 게임처럼 키 포즈 단위로 끊어서 움직입니다. 키 포즈마다 그린 그림(스프라이트)을 넣으면 그 그림으로 바뀝니다 ([docs/SPRITES.md](docs/SPRITES.md)).

## 실행

[Node.js](https://nodejs.org/) 20.19 이상이 필요합니다.

```bash
git clone https://github.com/gomsoonhyung/DanceBattle.git
cd DanceBattle
npm install
npm run dev        # 브라우저에서 http://localhost:5173
```

## 조작

|           | P1      | P2     |
| --------- | ------- | ------ |
| 이동      | W A S D | 방향키 |
| 약P / 강P | F / G   | K / L  |
| 약K / 강K | V / B   | , / .  |

게임패드: X 약P · Y 강P · A 약K · B 강K. 1번 패드는 P1, 2번 패드는 P2. 메뉴와 캐릭터 선택도 게임패드로 할 수 있다.

> 키보드 하나로 둘이 하면 키가 동시에 눌렸을 때 일부가 씹힐 수 있다(고스팅). 게임패드를 쓰면 가장 좋다.

**흐름**: 타이틀 → 캐릭터 선택(좌우로 고르고 약P 결정, 강P 취소) → 대전. 트레이닝 모드에서는 P1이 내 캐릭터와 연습 상대를 차례로 고른다. 대전이 끝나면 약P로 재대결, 강P로 캐릭터 다시 고르기.

**가드**: 뒤로 누르면 서서 가드, 뒤아래로 누르면 앉아 가드. 하단기는 앉아서만, 중단기(점프 공격 등)는 서서만 막을 수 있다.

**기본 기술**: → → 대시 · ← ← 백대시 (처음에 무적) · 붙어서 약P+약K 잡기 (가드 불가, 잡히는 순간 약P+약K로 풀기) · 넘어진 순간 버튼으로 빠른 기상 · 상대가 공격을 내미는 중에 맞히면 카운터 히트. 캐릭터마다 방향+버튼 특수기가 하나씩 있다. 자세한 내용은 타이틀의 **조작법**과 [기획서](docs/design/GAME_DESIGN.md).

**기타 키**: F1 판정 박스 보기 · ESC 메뉴 · (트레이닝) F2 연습 상대 행동 변경, R 위치 초기화

## 캐릭터

8가지 댄스 장르의 캐릭터가 있습니다. 기본 펀치와 킥도 장르의 동작으로 되어 있어요. 예를 들어 왁킹의 약P는 팔 채찍, 팝핑의 약P는 뻣뻣한 팝 잽입니다.

| 캐릭터      | 장르 · 타입         | 체력 | 대표 기술                                                                   |
| ----------- | ------------------- | ---- | --------------------------------------------------------------------------- |
| WAACKER     | 왁킹 · 연타형       | 950  | 휩 스톰(팔 채찍 5연타), **포즈**(게이지 충전)                               |
| KRUMPER     | 크럼프 · 파워형     | 1100 | 스톰프 웨이브(바닥 충격파), 버스트 러시(**아머**), 체스트 팝(**가드 불가**) |
| HIPHOPPER   | 힙합 · 리듬형       | 1000 | 러닝맨 러시, 크립 워크(하단 연타), 로저 래빗(**뒤로 빠지며 무적**)          |
| HIPHOP GIRL | 걸스힙합 · 테크닉형 | 950  | 헤어 플립, 힙 범프, 블로우 키스(**느린 하트 장풍**)                         |
| LOCKER      | 락킹 · 스피드형     | 950  | 엉클 샘 포인트(**앉으면 피하는 장풍**), 스쿠비 두 러시, 니 드롭(중단)       |
| HOUSE HEAD  | 하우스 · 풋워크형   | 1000 | 셔플 스텝(하단 연타), 스케이트 슬라이드(**높은 공격 밑으로 통과**)          |
| POPPER      | 팝핑 · 견제형       | 1000 | 웨이브(장풍), 로봇(**아머**), 애니메이션 대시(**잔상 + 무적**)              |
| B-BOY       | 브레이킹 · 올라운더 | 1000 | 윈드밀(하단), 헤드스핀, 프리즈(**반격**), 스와이프 킥(중단)                 |

- 모든 캐릭터는 **→↓↘ + 버튼**으로 대공기를 쓸 수 있습니다 (발동 직후 무적).
- **초필살기**는 그루브 게이지가 MAX일 때 **↓↘→↓↘→ + P** 또는 **강P+강K 동시**.
- 캐릭터별 전체 기술표는 **캐릭터 선택 화면**과 **연습 모드 기술 가이드**에서 볼 수 있습니다.

## 연습 모드

타이틀에서 **2. 트레이닝**을 고르면, 내 캐릭터와 연습 상대를 고른 뒤 연습할 수 있습니다.

| 키        | 기능                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------- |
| **1 ~ 9** | 기술 가이드에서 연습할 기술 고르기                                                                |
| **Space** | **커맨드 시범**: 캐릭터가 직접 커맨드를 입력해 기술을 보여 주고, 입력 중인 방향에 불이 들어옵니다 |
| **Tab**   | 기술 가이드 보이기 / 숨기기                                                                       |
| **F2**    | 연습 상대 행동 바꾸기 (서 있기 / 앉기 / 점프 / 자동 가드)                                         |
| **R**     | 위치 초기화                                                                                       |
| **F1**    | 판정 박스 보기                                                                                    |

- 기술을 직접 성공하면 **SUCCESS!** 와 함께 가이드 목록에 성공 횟수(✔)가 올라갑니다.
- 화면 오른쪽 끝의 **입력 기록**에 방금 누른 방향과 버튼이 남아서, 커맨드가 왜 안 나갔는지 확인할 수 있어요.
- 체력은 자동으로 회복되고, 그루브 게이지는 항상 가득 차 있어서 초필살기도 계속 연습할 수 있습니다.
