# B-BOY FIGHTER

비보이 동작으로 싸우는 2D 대전 격투 게임 (취미 프로젝트).
TypeScript + Vite + Canvas 2D. 그래픽은 코드로 그리는 스틱맨이다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 로직 테스트 (커맨드 인식, 타격/가드, 초필살기 등)
npm run build      # 배포용 빌드 → dist/
```

- `http://localhost:5173/?gallery`: 모든 동작을 반복 재생해서 보여준다
- `http://localhost:5173/?gallery=windmill`: 해당 동작을 프레임별로 나열한다 (동작 id는 `moves.ts` 참고)

## 조작

| | P1 | P2 |
|---|---|---|
| 이동 | W A S D | 방향키 |
| 약P / 강P | F / G | K / L |
| 약K / 강K | V / B | , / . |

게임패드: X 약P · Y 강P · A 약K · B 강K. 1번 패드는 P1, 2번 패드는 P2.

> 키보드 하나로 둘이 하면 키가 동시에 눌렸을 때 일부가 씹힐 수 있다(고스팅). 게임패드를 쓰면 가장 좋다.

**가드**: 뒤로 누르면 서서 가드, 뒤아래로 누르면 앉아 가드. 하단기는 앉아서만, 중단기(점프 공격, 스와이프 킥)는 서서만 막을 수 있다.

**기타 키**: F1 판정 박스 보기 · ESC 메뉴 · (트레이닝) F2 더미 행동 변경, R 위치 초기화

## 기술표

| 기술 | 커맨드 | 특징 |
|---|---|---|
| 윈드밀 | ↓↘→ + P | 전진하며 4회 공격, **하단**, 마지막 타격에 다운 |
| 에어플레어 | ↓↘→ + K | 빠르게 전진하며 2회 공격, 다운 |
| 헤드스핀 | →↓↘ + P | 대공기, 발동 직후 무적, 띄움 |
| 프리즈 | ↓↙← + P | 반격 자세. 이때 맞으면 플립 킥으로 자동 반격 |
| 스와이프 킥 | ↓↙← + K | 뛰어들며 차기, **중단** |
| 파워무브 콤보 (초필살기) | ↓↘→↓↘→ + P 또는 강P+강K | 그루브 게이지 MAX 필요 |

기본기는 서서/앉아서 × 약P/강P/약K/강K와 점프 공격 2종이다. 약공격은 맞았을 때 필살기로 캔슬할 수 있고, 앉아 강P(업 스윙)는 상대를 띄운다.

**콤보 예시**: 앉아 약K → 앉아 약P → 윈드밀 / 앉아 강P(띄움) → 헤드스핀

## 구조

```
src/
├── core/          고정 60fps 상수, 수학 유틸
├── input/         키보드/게임패드 입력, 프레임 단위 입력 버퍼 (커맨드 인식)
├── anim/pose.ts   스틱맨 뼈대, 포즈 키프레임 보간
├── fighter/       캐릭터 상태 머신, 기술 데이터 형식(types.ts)
├── characters/
│   └── bboy/      비보이 포즈(poses.ts)와 기술 데이터(moves.ts)
├── game/          대전 진행(match.ts), 타격 판정(combat.ts)
├── render/        화면 그리기 (무대, 스틱맨, HUD, 이펙트)
├── audio/         합성 효과음
└── debug/         동작 갤러리
```

설계 원칙:
- **게임 로직(`game/`, `fighter/`)은 렌더링과 분리되어 있다.** 나중에 2.5D/3D로 바꿔도 `render/`만 교체하면 된다.
- **로직은 결정론적이다.** 같은 입력이면 항상 같은 결과가 나온다(테스트로 확인). 나중에 온라인 롤백 넷코드를 붙일 때 필요하다.
- **기술은 데이터다.** `moves.ts`에서 프레임, 히트박스, 데미지를 고치면 바로 반영된다. F1로 판정 박스를 보면서 조정하면 편하다.

## 기술 추가/수정하기

`src/characters/bboy/moves.ts`에서 `MoveDef`를 하나 만들고 `BBOY_MOVES` 목록에 넣는다. 커맨드 기술이라면 `index.ts`의 `specials`에도 등록한다.

포즈 각도 규칙은 `src/anim/pose.ts` 맨 위 주석을 참고한다. 지면 스냅이 기본으로 켜져 있어서, 포즈를 만들 때 몸의 높이는 신경 쓰지 않아도 된다(가장 낮은 부위가 자동으로 바닥에 닿는다).
