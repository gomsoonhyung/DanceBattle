# 캐릭터 · 기술 만들기 가이드

새 캐릭터나 기술을 만드는 방법, 포즈 각도 규칙, 기술 데이터 필드, 프레임 데이터 기준을 정리했습니다.
기존 캐릭터 코드(`src/characters/krump/`)를 옆에 띄워 놓고 같이 보면 가장 빨라요.

## 1. 새 캐릭터 추가 순서

예시: 팝핑 캐릭터 `popper`

1. **폴더 만들기**: `src/characters/popping/`
2. **`poses.ts`**: 기본 자세와 동작
   - `STAND`(서기), `CROUCH`(앉기) 포즈를 만든다
   - `baseAnims(STAND, CROUCH)`를 부르면 피격·가드·점프·다운·기상 동작이 자동으로 만들어진다
   - 캐릭터 개성이 드러나는 `idle`(대기), `walkF`/`walkB`(걷기), `crouch`, `win`(승리)만 직접 만든다
3. **`moves.ts`**: 기본기 10개(서서/앉아서 × 약P·강P·약K·강K + 점프 2개), 필살기, 초필살기. **기술 도우미(`builders.ts`)** 를 쓰면 짧게 쓸 수 있다 (아래 4장). 기본기도 장르 동작으로 만들어 주세요.
4. **`index.ts`**: `CharacterDef` 작성 (이름, 체력, 외형, 소개, 스탯, 커맨드, 걷기·점프 속도)
5. **등록**: `src/characters/index.ts`의 `CHARACTERS` 배열에 추가하면 선택 화면에 나온다
6. **확인**: 갤러리(`?gallery&char=popper`), 트레이닝 모드, `npm run check`

`src/game/match.test.ts`의 "캐릭터 데이터" 테스트가 **모든 캐릭터를 자동으로 검사**합니다. 기술 id가 잘못 연결됐거나, 판정 프레임이 기술 길이를 넘거나, 필살기 커맨드가 안 나가면 테스트가 실패해요.

## 2. 포즈 만들기

포즈는 관절 각도의 묶음입니다. 캐릭터가 **오른쪽을 본다고 생각하고** 만드세요. 왼쪽을 볼 때는 자동으로 뒤집힙니다.

```ts
{
  x: 0, y: 82,      // 골반 위치. 지면 스냅이 켜져 있으면 y는 신경 안 써도 됨
  rot: 0,           // 몸 전체 회전. + = 앞으로 넘어감, 180 = 물구나무
  torso: 8,         // 상체 기울기. + = 앞으로 숙임
  head: -5,         // 상체 대비 고개
  aF: [40, 100],    // 앞팔 [어깨, 팔꿈치]
  aB: [25, 110],    // 뒷팔
  lF: [15, -12],    // 앞다리 [고관절, 무릎]
  lB: [-12, -6],    // 뒷다리
}
```

### 각도 치트시트

| 부위           | 0도                   | + 방향                | 자주 쓰는 값                                |
| -------------- | --------------------- | --------------------- | ------------------------------------------- |
| 어깨 `aF[0]`   | 팔이 몸통 따라 아래로 | 앞으로 들어 올림      | 90 = 앞으로 쭉, 180 = 머리 위로, -40 = 뒤로 |
| 팔꿈치 `aF[1]` | 쭉 폄                 | 주먹이 앞·위로 접힘   | 100 전후 = 가드 자세                        |
| 고관절 `lF[0]` | 다리가 수직 아래      | 다리가 앞으로         | 90 = 앞차기 높이, -30 = 뒤로                |
| 무릎 `lF[1]`   | 쭉 폄                 | (보통 음수) 뒤로 접힘 | -90 = 직각, -120 = 깊게 접음                |

예시:

- 앞으로 주먹 뻗기: `aF: [90, 0]`
- 앞차기: `lF: [85, 0]`
- 무릎 들기: `lF: [90, -110]`
- 쪼그려 앉기: `lF: [85, -100], lB: [45, -115]`

**몸을 크게 돌린 자세**(헤드스핀, 프리즈 등)에서는 각도가 몸 기준이라 헷갈립니다. `common.ts`의 헬퍼를 쓰면 **화면 기준 각도**로 쓸 수 있어요.

```ts
// 몸이 115도 돌아간 상태에서, 팔을 화면 기준 수직 아래(바닥 짚기)로
aF: [armW(0, 115), 0];
// 다리를 화면 기준 앞쪽 위(110도)로
lF: [legW(110, rot), 0];
// 화면 기준 각도: 0 = 아래, 90 = 앞, 180 = 위, -90 = 뒤
```

**기존 포즈를 조금만 바꾸기**: `pose(STAND, { torso: 20, aF: [90, 0] })`처럼 바꿀 부분만 적습니다.

## 3. 애니메이션

```ts
const anim: Anim = {
  keys: [
    { f: 0, p: STAND }, // 0프레임에 이 포즈
    { f: 4, p: PUNCH }, // 4프레임에 이 포즈 (사이는 부드럽게 보간)
    { f: 14, p: STAND },
  ],
  loop: 40, // (선택) 반복 주기. 대기·걷기 동작에 사용
  pivot: 'head', // (선택) 회전 기준 관절. 'hip'(기본) | 'neck' | 'head'. 헤드스핀은 머리 기준으로 돈다
  snap: false, // (선택) 지면 스냅 끄기. 점프 공격처럼 공중 동작일 때
};
```

- **지면 스냅**(기본으로 켜짐): 가장 낮은 신체 부위가 자동으로 바닥에 닿습니다. 그래서 포즈마다 높이를 맞추지 않아도 돼요.
- **살짝 뛰는 동작**은 포즈에 `lift: 50`을 주면 스냅한 뒤에 그만큼 띄웁니다 (락킹 니 드롭 참고).
- **회전 기술**은 `genKeys(시작, 끝, 간격, (프레임, 번호) => 포즈)`로 키프레임을 생성합니다 (비보이 윈드밀 참고).
- 각도는 **숫자 그대로 보간**됩니다. `rot: 0 → 360`은 한 바퀴를 돌고, `rot: 350 → 10`은 거꾸로 340도를 돕니다.

## 4. 기술 도우미 (`builders.ts`)

키프레임과 히트 데이터를 매번 손으로 쓰지 않도록 도우미 함수를 준비해 두었습니다. 새 캐릭터 5명(왁킹, 힙합, 걸스힙합, 하우스, 팝핑)은 전부 이걸로 만들었어요.

| 함수          | 용도                                                                 | 예시                                  |
| ------------- | -------------------------------------------------------------------- | ------------------------------------- |
| `strike()`    | 한 번 때리는 기술 (기본기, 대공기, 돌진기)                           | 왁킹 `sLP`, 하우스 `skateSlide`       |
| `airStrike()` | 점프 공격 (기본 중단)                                                | 모든 캐릭터의 `jL`, `jH`              |
| `combo()`     | 여러 번 때리는 기술. `kind: 'super'`면 초필살기 설정이 자동으로 붙음 | 왁킹 `whipStorm`, 하우스 `houseParty` |
| `shooter()`   | 장풍                                                                 | 팝핑 `wave`, 걸스힙합 `blowKiss`      |
| `moveTable()` | 기술 배열 → 캐릭터에 넣을 사전                                       | 각 `moves.ts` 맨 아래                 |

```ts
const sLP = strike({
  id: 'sLP',
  name: '휩',
  base: STAND,                                   // 시작·끝 자세
  windup: pose(STAND, { aF: [178, -20] }),       // 예비 동작 (선택)
  hit: pose(STAND, { torso: 10, aF: [88, 5] }),  // 판정이 나오는 순간의 자세
  startup: 5, active: 3, recovery: 7,            // 발생 · 지속 · 빈틈 (프레임)
  box: { x: 20, y: 110, w: 82, h: 40 },
  damage: 28,                                    // 경직·타격감은 데미지로 자동 계산 (extra로 덮어쓰기 가능)
  cancel: true,                                  // 적중 시 필살기 캔슬
  chain: ['sLP', 'cLP'],
});

const whipStorm = combo({
  id: 'whipStorm', name: '휩 스톰', desc: '양팔을 번갈아 휘두르는 5연타',
  base: STAND, poses: [WHIP_A, WHIP_B],          // 타격마다 번갈아 쓰는 자세
  start: 7, interval: 5, count: 5,               // 7프레임부터 5프레임 간격으로 5번
  box: {...}, damage: 20,
  finish: { pose: FINISH, delay: 6, damage: 40 },  // 마무리 타격 (자동으로 다운)
  recovery: 16,
  more: { velocity: [{ from: 6, to: 28, vx: 1.5 }] },  // 나머지 MoveDef 필드
});
```

## 5. 기술 데이터 (`MoveDef`)

```ts
const sLP: MoveDef = {
  id: 'sLP',
  name: '크럼프 잽',        // 화면·기술표에 나오는 이름
  kind: 'normal',          // 'normal' | 'special' | 'super'
  total: 16,               // 전체 길이 (프레임)
  anim: { keys: [...] },
  hits: [{ frames: [5, 7], box: {...}, damage: 35, hitstun: 15, blockstun: 10, level: 'mid' }],
  cancelWindow: [5, 11],   // 맞혔을 때 이 구간에 필살기로 캔슬 가능
  chainInto: ['sLP', 'cLP'],
};
```

| 필드                       | 설명                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `total`                    | 기술 전체 프레임. 끝나면 대기 상태로 돌아간다                                   |
| `hits`                     | 공격 판정 목록. 여러 개면 다단히트                                              |
| `cancelWindow`             | 적중·가드 시 필살기/초필살기로 캔슬 가능한 프레임 구간                          |
| `chainInto`                | 적중·가드 시 이어서 쓸 수 있는 기본기 id (약P → 약P 연타 등)                    |
| `velocity`                 | `[{ from, to, vx }]` 구간별 전진 속도 (보는 방향 기준, px/프레임)               |
| `invuln`                   | `[시작, 끝]` 무적 프레임 (대공기의 발동 직후 등)                                |
| `armor`                    | `[시작, 끝]` 슈퍼아머. 이 구간에 한 번은 맞아도 기술이 계속된다                 |
| `hurtbox`                  | 이 기술 중 맞는 판정을 바꿈 (낮게 도는 기술은 작게)                             |
| `counter`                  | `{ from, to, into }` 반격 자세. 이 구간에 맞으면 `into` 기술이 나감             |
| `projectile`               | 장풍 (아래 참고)                                                                |
| `air`                      | 점프 공격. 착지하면 끝난다                                                      |
| `meterCost`, `superFreeze` | 초필살기용: 게이지 소모량(100), 발동 연출 정지 프레임(40)                       |
| `meterGain`                | `{ frame, amount }` 그 프레임에 게이지를 채운다 (왁킹 포즈)                     |
| `trail`                    | 잔상 연출 (팝핑 애니메이션 대시)                                                |
| `desc`                     | 연습 모드 기술 가이드에 나오는 한 줄 설명. **필살기·초필살기에는 꼭 써 주세요** |

### 공격 판정 (`HitDef`)

| 필드                    | 설명                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| `frames`                | `[시작, 끝]` 판정이 나오는 프레임. 기술 시작이 1프레임                                   |
| `box`                   | `{ x, y, w, h }` 캐릭터 발밑 기준. x는 보는 방향 +, y는 위쪽 +. 서 있는 몸 높이는 약 175 |
| `damage`                | 데미지                                                                                   |
| `hitstun` / `blockstun` | 맞힌 / 가드시킨 상대가 움직이지 못하는 프레임                                            |
| `level`                 | `'mid'`(서서·앉아서 가드), `'low'`(앉아서만), `'overhead'`(서서만)                       |
| `push`                  | 넉백 거리 (기본 6)                                                                       |
| `hitstop`               | 타격 순간 양쪽이 멈추는 프레임, 타격감 (기본 8, 강공격 11~14)                            |
| `knockdown`             | 다운시킨다                                                                               |
| `launch`                | `{ vx, vy }` 띄운다 (공중 콤보 시작)                                                     |
| `chip`                  | 가드해도 깎이는 데미지 (필살기용)                                                        |
| `unblockable`           | 가드 불가                                                                                |
| `heavy`                 | 강공격 이펙트와 소리                                                                     |

### 장풍 (`ProjectileDef`)

```ts
projectile: {
  frame: 14,                 // 기술 몇 프레임째에 발사
  x: 60, y: 20,              // 발사 위치 (캐릭터 기준)
  vx: 6.5, life: 70,         // 속도(px/프레임), 유지 시간(프레임)
  box: { x: -28, y: -20, w: 56, h: 40 },  // 장풍 중심 기준 판정
  kind: 'shockwave',         // 모양: shockwave(충격파) | spark(별빛) | wave(파동) | heart(하트). 새 모양은 render/renderer.ts의 drawProjectile에
  hit: { damage: 60, hitstun: 20, blockstun: 16, level: 'low', chip: 8 },
}
```

장풍의 **높이**(`y`)가 전략을 만듭니다. 락킹 장풍은 높게 날아가서 앉으면 피하고, 크럼프 장풍은 바닥을 타서 하단 가드를 해야 해요. 높이가 다른 장풍끼리는 엇갈리고, 같은 높이면 서로 부딪혀 사라집니다.

## 6. 프레임 데이터 기준표

처음 만든 세 캐릭터(비보이·크럼프·락킹)의 값입니다. 새 기술을 만들 때 이 범위에서 시작하면 밸런스가 크게 무너지지 않아요.
("발생"은 첫 판정이 나오는 프레임)

| 분류        | 발생           | 전체 길이  | 데미지              | 예시                                           |
| ----------- | -------------- | ---------- | ------------------- | ---------------------------------------------- |
| 약P / 약K   | 4 ~ 7          | 12 ~ 20    | 22 ~ 45             | 락킹 앉아 약P가 가장 빠름 (4)                  |
| 강P / 강K   | 8 ~ 12         | 28 ~ 38    | 70 ~ 105            | 크럼프가 가장 느리고 셈                        |
| 점프 공격   | 4 ~ 8          | (착지까지) | 45 ~ 90             | 전부 중단(`overhead`)                          |
| 대공 필살기 | 5 ~ 6          | 46 ~ 52    | 90 ~ 130            | 발동 직후 무적 7~9프레임, 헛치면 큰 빈틈       |
| 돌진 필살기 | 8 ~ 15         | 42 ~ 50    | 90 ~ 140            |                                                |
| 장풍        | 12 ~ 14 (발사) | 40 ~ 46    | 50 ~ 60             |                                                |
| 느린 특수기 | 16 ~ 21        | 42 ~ 50    | 80 ~ 120            | 중단, 가드 불가 등. 보고 대처할 수 있게 느리게 |
| 초필살기    | 8 ~ 10         | 80 ~ 100   | 310 ~ 395 (보정 전) | 발동 무적 12~20프레임                          |

### 캔슬 콤보가 이어지게 하려면

기본기를 맞히고 필살기로 캔슬했을 때 콤보가 되려면, 대략 이렇게 맞추면 됩니다.

> **필살기의 발생 프레임 < 기본기의 `hitstun`**

예: 비보이 앉아 약P(`hitstun` 13) → 윈드밀(발생 9)은 이어집니다. 윈드밀 발생이 14였을 때는 1프레임 차이로 끊겼어요.
정확한 확인은 테스트로 하는 게 확실합니다. `match.test.ts`의 "콤보:" 테스트를 복사해서 쓰세요.
