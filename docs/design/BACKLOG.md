# 개선할 부분과 필요한 내용 (백로그)

> 2026-10-15 기준. 지금 게임에 **없거나 약한 것**을 한곳에 모았다. 위에서부터 중요도 순.
> 상태: ✅ 완료 · 🔶 일부 · ⬜ 아직. 크기: S(한 번 작업) · M(몇 번) · L(큰 작업).

## 1. 타격감 · 속도감

이번에 **그림을 새로 만들지 않고** 연출만으로 넣은 것. 모두 표시·소리 전용이라 게임 숫자(데미지·프레임)는 그대로다.

| 상태 | 항목                        | 내용                                                                                  |
| ---- | --------------------------- | ------------------------------------------------------------------------------------- |
| ✅   | 히트스톱 떨림               | 맞아서 멈춘 동안 맞은 쪽이 제자리에서 덜덜 떤다 (스트리트 파이터식)                   |
| ✅   | 세기별 화면 흔들림          | 데미지에 비례 (약 30 → 작게, 강 100 → 크게), 카운터·잡기·KO는 더 크게                 |
| ✅   | 임팩트 줌                   | 강공격·카운터·잡기·KO 순간 타격 지점으로 화면을 살짝 당긴다                           |
| ✅   | 집중선                      | 강타·카운터·잡기·KO 때 타격 지점에서 방사형 선이 퍼진다                               |
| ✅   | 잔상                        | 대시·백대시·빠른 돌진·초필살기·연속 회전 중인 파워무브가 실제 그림으로 잔상을 남긴다  |
| ✅   | 속도선                      | 빠르게 움직이는 캐릭터 뒤로 가로 선                                                   |
| ✅   | 휘두르는 소리               | 기술이 나가는 순간 (약 < 강 < 필살 < 초필)                                            |
| ✅   | 세기별 타격음               | 데미지가 클수록 낮고 길게, 강공격은 저음 한 겹 더                                     |
| ✅   | 콤보 숫자 튀기              | 타수가 오를 때마다 커졌다 줄어듦, 5타부터 노랑·10타부터 빨강                          |
| ✅   | 카운터 붉은 섬광            | 카운터 히트 때 화면이 살짝 붉게                                                       |
| ⬜   | 히트스톱 데미지 비례 (S)    | 지금은 약 8 / 강 11 고정 → 데미지에 맞춰 조금씩. **게임 숫자가 바뀌어 밸런스에 영향** |
| ⬜   | 벽꽝·바닥 바운드 (M)        | 강한 마무리에 벽에 부딪혀 튕기거나 바닥에서 한 번 튀기 (콤보 연장 수단)               |
| ⬜   | 카메라 따라가기 (M)         | 지금은 화면 = 무대 전체. 무대를 넓히고 두 캐릭터 가운데를 따라가며, 공중 콤보 때 위로 |
| ⬜   | 초필 마무리 연출 (S)        | 마지막 타격에 화면 정지 + 배경 반전 + 슬로모션                                        |
| ⬜   | 장르별 타격 이펙트 그림 (M) | 휩(왁킹)·전기(팝핑)·충격파(크럼프) 전용 이펙트 그림 (지금은 공용 스파크 + 코드 궤적)  |
