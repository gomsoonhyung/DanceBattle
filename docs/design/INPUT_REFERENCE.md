# 키 조합 정리 (스트리트 파이터 참고)

> 목적: 캐릭터 한 명에 **기술이 몇 개 필요한지**, **어떤 춤 동작을 어떤 커맨드에 넣을지** 정하기 위한 표.
> 기준은 스트리트 파이터 6(이하 SF6)이고, 우리 게임(버튼 4개)에 맞춰 줄였다.

## 1. 방향 표기 (오른쪽을 볼 때)

```
7 8 9      ↖ ↑ ↗
4 5 6  =   ← · →      5 = 아무것도 안 누름
1 2 3      ↙ ↓ ↘
```

왼쪽을 보면 좌우가 뒤집힌다. 6은 항상 "상대 쪽", 4는 "상대 반대쪽".

## 2. 버튼

|      | SF6                 | 우리 게임     |
| ---- | ------------------- | ------------- |
| 펀치 | 약·중·강 (LP MP HP) | 약·강 (LP HP) |
| 킥   | 약·중·강 (LK MK HK) | 약·강 (LK HK) |
| 합계 | 6개                 | **4개**       |

버튼이 적은 만큼 SF6보다 기술 수를 줄이는 게 자연스럽다.

## 3. 키 조합 종류 전체

### 3-1. 일반기 (버튼 하나)

| 입력         | 뜻          | SF6 개수 | 우리 게임        | 춤 동작을 넣는 요령                           |
| ------------ | ----------- | -------- | ---------------- | --------------------------------------------- |
| 버튼         | 서서 공격   | 6        | **4** ✅         | 그 장르의 짧은 기본 동작 (잽, 포인트, 킥)     |
| 2 + 버튼     | 앉아서 공격 | 6        | **4** ✅         | 낮은 자세 동작 (바닥 치기, 로우 스톰프, 스윕) |
| 점프 중 버튼 | 점프 공격   | 6        | **2** ✅ (약·강) | 공중 동작 (다이브, 공중 킥, 점프 스톰프)      |

### 3-2. 특수기 (방향 + 버튼, 커맨드 일반기)

| 입력     | 흔한 쓰임 (SF6 예)                             | 우리 게임                    |
| -------- | ---------------------------------------------- | ---------------------------- |
| 6 + 버튼 | 앞으로 나가는 기술, **중단** (류 6HP 내려치기) | ✅ 지원 (지금 캐릭터당 1개)  |
| 4 + 버튼 | 뒤로 빠지며 치기, 대공 성질 (켄 4HK)           | ✅ 지원 (아직 안 씀)         |
| 3 + 버튼 | 낮게 미끄러지는 **하단** (춘리 3HK)            | ✅ 지원 (하우스·비보이가 씀) |
| 1 + 버튼 | 드묾                                           | ✅ 지원                      |

SF6 캐릭터는 보통 **특수기 2~5개**.

### 3-3. 타겟 콤보 (정해진 버튼 순서)

| 입력        | 예                     | 우리 게임                |
| ----------- | ---------------------- | ------------------------ |
| 버튼 → 버튼 | 류 HP → HK, 켄 MP → HP | ⚠️ 일부 (약 → 약 체인만) |

춤의 **2~3동작 연속 루틴**을 넣기 좋다 (예: 락킹 포인트 → 업 락 → 포인트). SF6는 캐릭터당 1~3개.

### 3-4. 잡기

| 입력                  | 뜻            | 우리 게임 |
| --------------------- | ------------- | --------- |
| 약P + 약K             | 앞으로 던지기 | ✅        |
| 4 + 약P + 약K         | 뒤로 던지기   | ✅        |
| 붙잡혔을 때 약P + 약K | 잡기 풀기     | ✅        |

### 3-5. 필살기 커맨드

| 입력           | 이름             | 모양       | SF6 대표 예              | 쓰기 좋은 기술                | 우리 게임    |
| -------------- | ---------------- | ---------- | ------------------------ | ----------------------------- | ------------ |
| **236** + 버튼 | 앞 반원 (파동권) | ↓↘→        | 파동권                   | 장풍, 돌진                    | ✅           |
| **214** + 버튼 | 뒤 반원          | ↓↙←        | 용권선풍각               | 돌거나 특이한 기술, 반격      | ✅           |
| **623** + 버튼 | 승룡             | →↓↘        | 승룡권                   | **대공** (시작 무적)          | ✅           |
| 41236 + 버튼   | 앞 반바퀴        | ←↙↓↘→      | 춘리 기공권, 잡기 필살기 | 큰 동작, 커맨드 잡기          | ❌ 추가 필요 |
| 63214 + 버튼   | 뒤 반바퀴        | →↘↓↙←      | 기스 계열                | 반격기, 큰 동작               | ❌ 추가 필요 |
| 22 + 버튼      | 아래 두 번       | ↓↓         | 일부 캐릭터 자세 바꾸기  | **스탠스 전환**, 포즈         | ❌ 추가 필요 |
| [4]6 + 버튼    | 뒤 모았다 앞     | ← 길게 → → | 가일 소닉붐              | 모았다 터뜨리는 동작          | ❌ 추가 필요 |
| [2]8 + 버튼    | 아래 모았다 위   | ↓ 길게 → ↑ | 가일 서머솔트            | 위로 튀는 대공                | ❌ 추가 필요 |
| 360 + 버튼     | 한 바퀴          | 모든 방향  | 장기에프 스크류          | **커맨드 잡기** (파트너 동작) | ❌ 추가 필요 |
| 버튼 연타      | 연타             | P P P      | 혼다 백열장              | 빠른 연속 동작 (왁 연타)      | ❌ 추가 필요 |

> **같은 커맨드라도 P와 K로 2개**가 된다 (236P / 236K). SF6는 여기에 약·중·강 세기와 강화판(OD)까지 있어서 같은 커맨드에서 버전이 4~5개 나온다. 우리는 P / K 두 갈래만 쓴다.

SF6 캐릭터는 보통 **필살기 4~6종**.

### 3-6. 초필살기

| 입력         | SF6              | 우리 게임             |
| ------------ | ---------------- | --------------------- |
| 236236 + P   | Lv1·Lv3 초필살기 | ✅ (게이지 100)       |
| 214214 + P/K | Lv2 초필살기     | ❌ 추가 필요          |
| 강P + 강K    | —                | ✅ (초보용 단축 입력) |

SF6는 캐릭터당 **3개**(게이지 1·2·3칸). 우리는 지금 1개.

### 3-7. 이동·시스템

| 입력                 | 뜻                          | 우리 게임                                    |
| -------------------- | --------------------------- | -------------------------------------------- |
| 66                   | 앞 대시                     | ✅                                           |
| 44                   | 백대시 (처음 무적)          | ✅                                           |
| 4 (뒤로 걷기)        | 서서 가드                   | ✅                                           |
| 1                    | 앉아 가드                   | ✅                                           |
| 넘어진 순간 버튼     | 빠른 기상                   | ✅                                           |
| 중P + 중K (SF6)      | 패리 (막기 + 게이지)        | ❌ 없음 (버튼 2개 조합으로 넣을 수 있음)     |
| 강P + 강K (SF6)      | 드라이브 임팩트 (아머 반격) | ⚠️ 우리는 이 자리를 초필살기 단축으로 씀     |
| 도발 (SF6 버튼 조합) | 도발                        | ❌ 없음 → **춤 프리스타일 도발**에 쓰기 좋음 |

## 4. 캐릭터 한 명에 기술이 몇 개 필요한가

| 분류                 | SF6 보통     | 우리 게임 지금 | 추천         |
| -------------------- | ------------ | -------------- | ------------ |
| 서서 일반기          | 6            | 4              | 4            |
| 앉아 일반기          | 6            | 4              | 4            |
| 점프 공격            | 6            | 2              | 2            |
| 특수기 (방향 + 버튼) | 2~5          | 1              | **2~3**      |
| 타겟 콤보            | 1~3          | 0              | **0~1**      |
| 잡기                 | 2 (앞·뒤)    | 1 (+뒤)        | 1            |
| 필살기               | 4~6종        | 4~5            | **5**        |
| 초필살기             | 3            | 1              | **1~2**      |
| 도발                 | 1            | 0              | **1** (선택) |
| **합계**             | **약 35~40** | **약 23**      | **약 25~28** |

> 춤 동작 기준으로 보면 **장르당 25개 안팎의 동작**이 필요하다. 이 중 **필살기 5개 + 초필살기 1개 + 특수기 2개 = 약 8개**가 "그 장르를 대표하는 동작" 자리이고, 나머지 일반기 14개는 장르의 기본기 중 짧은 것으로 채우면 된다.

### 커맨드 자리 배정의 관습 (SF 캐릭터 대부분이 따름)

| 자리        | 관습적으로 넣는 기술                      |
| ----------- | ----------------------------------------- |
| 236P        | 장풍 또는 대표 기술                       |
| 236K        | 돌진기                                    |
| 623P        | 대공                                      |
| 214P / 214K | 특이한 기술 (반격, 회전, 중단 점프, 자세) |
| 6 + 강P     | 중단                                      |
| 3 + 킥      | 미끄러지는 하단                           |
| 236236P     | 대표 기술을 크게 만든 초필살기            |

이 관습을 지키면 다른 격투 게임을 해 본 사람이 바로 이해한다.

## 5. 채워 보는 표 (생각해 보실 때)

장르 하나당 이 표를 채우시면 됩니다. 빈칸은 비워 두셔도 됩니다. 제가 장르 레퍼런스에서 골라 제안합니다.

| 자리        | 입력             | 넣고 싶은 춤 동작 | 비고                        |
| ----------- | ---------------- | ----------------- | --------------------------- |
| 서서 약P    | LP               |                   | 짧고 빠른 동작              |
| 서서 강P    | HP               |                   | 크고 강한 동작              |
| 서서 약K    | LK               |                   |                             |
| 서서 강K    | HK               |                   |                             |
| 앉아 약P    | 2LP              |                   | 낮은 자세                   |
| 앉아 강P    | 2HP              |                   | 위로 치는 동작이면 대공     |
| 앉아 약K    | 2LK              |                   | 하단                        |
| 앉아 강K    | 2HK              |                   | 하단, 넘어뜨림              |
| 점프 약     | 공중 LP/LK       |                   |                             |
| 점프 강     | 공중 HP/HK       |                   | 내리찍으면 중단             |
| 특수기 1    | 6 + ?            |                   | 중단 또는 앞으로 나감       |
| 특수기 2    | 3 + ? 또는 4 + ? |                   | 하단 또는 뒤로 빠짐         |
| 잡기        | LP+LK            |                   | 파트너 동작                 |
| 필살기 1    | 236P             |                   | 장풍·대표                   |
| 필살기 2    | 236K             |                   | 돌진                        |
| 필살기 3    | 623P             |                   | 위로 올라가는 동작          |
| 필살기 4    | 214P             |                   |                             |
| 필살기 5    | 214K             |                   |                             |
| 초필살기    | 236236P          |                   | 기본기를 이어 붙인 쇼케이스 |
| (추가) 도발 | ?                |                   | 프리스타일 포즈             |

> 지금 들어 있는 기술은 [FRAME_DATA.md](FRAME_DATA.md)의 캐릭터별 표에서 볼 수 있습니다. 동작을 정하는 기준은 [CHARACTER_PLAYBOOK.md](CHARACTER_PLAYBOOK.md) 10절.

## 6. 새로 넣을 수 있는 입력 (원하시면 추가)

| 입력                     | 추가 작업 | 춤과 잘 맞는 쓰임                                |
| ------------------------ | --------- | ------------------------------------------------ |
| **도발** (예: 약K + 강P) | 작음      | 장르 프리스타일 포즈, 게이지 조금 충전           |
| **타겟 콤보**            | 작음      | 2~3동작 루틴 (락킹 포인트 → 락 → 포인트)         |
| **22 + 버튼** (스탠스)   | 중간      | 춤 스타일 바꾸기 (예: 하우스 잭킹 ↔ 로프팅 자세) |
| **41236 / 63214**        | 작음      | 큰 동작 필살기                                   |
| **모으기 [4]6 / [2]8**   | 중간      | "힘을 모았다 터뜨리는" 크럼프식 동작             |
| **214214 초필살기**      | 작음      | 장르의 두 번째 쇼케이스                          |
| **연타**                 | 작음      | 왁 연타, 팝 연타                                 |
| **360 커맨드 잡기**      | 중간      | 파트너 춤 동작                                   |
| **패리**                 | 큼        | (춤과 관계는 적음)                               |
