# 캐릭터 운영 기획서 (3차)

> [GAME_DESIGN.md](GAME_DESIGN.md)(시스템)와 [DANCE_REFERENCE.md](DANCE_REFERENCE.md)(장르 동작) 다음 단계.
> 각 캐릭터를 **어떻게 싸우는 캐릭터인지**, **어떤 기술을 언제 쓰는지**, **어떤 콤보가 이어지는지**를 정한다.
> 숫자는 [FRAME_DATA.md](FRAME_DATA.md)(자동 생성)가 기준이고, 콤보는 실제 게임 로직으로 시험해서 이어지는 것만 적었다.

## 0. 읽는 법

| 말         | 뜻                                                          |
| ---------- | ----------------------------------------------------------- |
| **견제**   | 멀리서 닿는 기술로 상대가 다가오지 못하게 함                |
| **러시**   | 붙어서 계속 공격하며 가드를 흔듦                            |
| **흔들기** | 하단(앉아 막기)과 중단(서서 막기)을 섞어 상대가 틀리게 만듦 |
| **대공**   | 점프해 오는 상대를 떨어뜨리는 기술 (623 커맨드, 시작 무적)  |
| **확정**   | 상대가 막아도 빈틈이 커서 반격이 무조건 들어가는 상황       |
| **+ / −**  | 유불리. 기술이 끝난 뒤 몇 프레임 먼저 움직이는지            |

### 콤보의 공통 규칙 (모든 캐릭터)

시험 결과 다음 규칙이 8명 모두에게 똑같이 통한다.

1. **약 → 약 → 필살기**: 약공격끼리는 체인으로 이어지고, 약공격은 필살기로 캔슬된다. 가장 기본.
2. **강P / 앉아 강P → 필살기**: 강공격 하나를 맞히고 바로 필살기 커맨드.
3. **필살기 → 초필살기**: 게이지 MAX일 때 필살기가 맞는 순간 236236P (또는 강P+강K).
4. **약 → 강 일반기는 이어지지 않는다**: 약공격의 경직이 강공격 발생보다 짧다. 강공격은 콤보의 **시작**이지 중간이 아니다.

> 이 4번 규칙은 일부러 둔다. "작게 시작해서 필살기로 끝낸다 / 크게 시작하면 바로 필살기"라는 단순한 구조가 처음 배우기 쉽다.

### 상성표 (가로가 유리한 쪽)

|              | 크럼프 | 왁킹 | 힙합 | 걸스힙합 | 락킹 | 하우스 | 팝핑 | 비보이 |
| ------------ | ------ | ---- | ---- | -------- | ---- | ------ | ---- | ------ |
| **크럼프**   |        | −    | =    | =        | −    | +      | −    | +      |
| **왁킹**     | +      |      | =    | =        | =    | −      | =    | −      |
| **힙합**     | =      | =    |      | =        | =    | =      | =    | =      |
| **걸스힙합** | =      | =    | =    |          | +    | =      | −    | =      |
| **락킹**     | +      | =    | =    | −        |      | =      | +    | =      |
| **하우스**   | −      | +    | =    | =        | =    |        | −    | =      |
| **팝핑**     | +      | =    | =    | +        | −    | +      |      | −      |
| **비보이**   | −      | +    | =    | =        | =    | =      | +    |        |

이유 한 줄씩:

- 크럼프는 장풍 캐릭터(왁킹·팝핑)와 긴 견제(락킹)에 약하고, 붙는 캐릭터(하우스·비보이)에는 아머로 이긴다.
- 왁킹은 긴 리치로 크럼프를 묶지만, 하단 러시(하우스)와 낮은 자세(비보이)에 약하다.
- 팝핑은 장풍으로 느린 캐릭터를 묶지만, 장풍 밑을 빠지는 비보이와 빠른 락킹에 약하다.
- 비보이는 낮은 자세로 장풍(팝핑·왁킹)을 통과한다.
- 힙합은 기준 캐릭터라 모두와 대등하다.

## 1. 크럼프 KRUMPER — "맞으면서 밀고 들어가는 파워"

| 체력        | 속도 | 리치 | 힘    | 난이도 |
| ----------- | ---- | ---- | ----- | ------ |
| 1150 (최고) | ★    | ★★   | ★★★★★ | ★★     |

**한 줄**: 느리고 짧지만 **아머**(6HP 피치 스윙, 236K 벅 러시)로 상대 견제를 맞으면서 들어가, 붙으면 하단 스톰프와 중단 피치 스윙으로 흔든다.

**게임 플랜**

1. **멀리서**: 236P 스톰프 웨이브(하단 장풍)를 굴려 상대를 앉게 만든다. 앉은 상대에게 214K 점프 스톰프(중단)로 뛰어든다.
2. **중거리**: 236K 벅 러시로 아머 돌진. 장풍과 약한 견제는 맞으면서 뚫는다.
3. **붙으면**: 약K 프론트 스톰프(서서 쓰는 하단) ↔ 6HP 피치 스윙(중단) 흔들기. 막아도 −2라 위험이 적다.
4. **수비**: 214P 찢기(가드 불가)는 느리다. 상대가 가드를 굳혔을 때만.

**기본 콤보** (시험 확인)

| 콤보                                 | 타수 | 용도                   |
| ------------------------------------ | ---- | ---------------------- |
| 2약K → 2약P → 236K 벅 러시           | 3    | 하단에서 시작하는 기본 |
| 강P 배트 스윙 → 236P 스톰프 웨이브   | 6    | 가장 큰 일반 콤보      |
| 2약K → 2약P → 236K → 236236P 킬 오프 | 6    | 게이지 MAX             |
| 6HP 피치 스윙(아머) → 236K           |      | 맞으면서 들어가 그대로 |

**약점과 대처**: 발이 느려 장풍에 묶인다 → 벅 러시 아머로 장풍째 뚫는다. 점프 공격은 빈틈이 커서 대공을 맞기 쉽다 → 점프보다 점프 스톰프(214K)를 쓴다.

**고칠 점 (데이터)**

- 일반기끼리 **링크가 하나도 없다** → 의도대로(느림). 대신 약P → 약P 체인은 이어진다.
- 강K 버킹 킥은 크럼프 동작 레퍼런스에 없다 → **스톰프 스텝**(크게 한 발 내디디며 쾅 + 체스트 팝)으로 바꾸기 (다음 작업).

## 2. 왁킹 WAACKER — "가장 긴 팔로 거리를 지배"

| 체력       | 속도 | 리치  | 힘  | 난이도 |
| ---------- | ---- | ----- | --- | ------ |
| 900 (최저) | ★★★  | ★★★★★ | ★★  | ★★★    |

**한 줄**: 리치 +30% 휩과 6LP 라인으로 **상대가 걸어 들어오는 순간을 계속 친다**. 붙으면 약하다.

**게임 플랜**

1. **중거리 유지**: 6LP 라인(가장 긴 일반기)과 약P 휩을 끝 거리에서 툭툭. 약P 휩은 막혀도 +1.
2. **멀리서**: 236P 왁 포즈 웨이브(장풍)로 견제하고, 214P 스트라이크 어 포즈로 게이지를 채운다 (+30).
3. **다가오면**: 236K 트월(앞뒤 판정 다단)로 밀어낸다. 점프는 623P 오버헤드 롤로.
4. **약점**: 하단은 앉아 약K·강K뿐이고 데미지 ×0.6. 상대를 무너뜨리기보다 깎는 캐릭터.

**기본 콤보**

| 콤보                                     | 타수 | 용도                                          |
| ---------------------------------------- | ---- | --------------------------------------------- |
| 강P 오버헤드 왁 → 236P 왁 포즈 웨이브    | 9    | 가장 큰 일반 콤보 (가까이서 파동이 바로 맞음) |
| 2약K → 2약P → 236K 트월                  | 6    | 하단 시작                                     |
| 2약K → 2약P → 236K → 236236P 디바 피날레 | 11   | 게이지 MAX                                    |

**운영 팁**: 포즈(214P)로 게이지를 모아 두면, 트월이 맞을 때마다 초필살기로 바꿀 수 있다. 체력이 낮으니 게이지를 빨리 쓰는 편이 낫다.

**고칠 점**

- 서서 쓰는 중단이 없다 → 의도대로 (흔들기 캐릭터가 아니다).
- 강K 트월 킥은 레퍼런스에 맞게 바뀌었다. 약K '포즈 킥'은 **익스텐션 킥**으로 이름·자세 정리 (다음 작업).

## 10. 내가 아는 춤 동작을 게임에 넣는 방법

### 10-1. 이렇게 알려 주세요 (양식)

한 동작에 아래 칸을 채워 주시면 됩니다. **다 채우지 않아도 됩니다.** 이름과 "어떻게 움직이는지"만 있어도 나머지는 제가 정해서 확인받겠습니다.

```
장르: 락킹
동작 이름: 스쿠봇
어떻게 움직이나: 머슬맨 자세로 한 바퀴 돌면서 스쿠비 킥을 두 번
  - 시작 자세: 두 팔을 어깨 위로 (머슬맨)
  - 가장 강조되는 순간: 발을 차는 순간
  - 끝 자세: 앞으로 숙여 락
  - 박자: 1-2(돌기) 3(킥) 4(킥) / 빠르게 / 멈춤 있음
게임에서 이런 느낌이면 좋겠다: 돌면서 앞뒤를 다 때리는 다단 공격
참고 영상(있으면): 링크와 몇 초 지점
```

영상 링크를 주시면 제가 직접 볼 수는 없지만, 영상을 보고 위 칸을 채워 주시는 데 도움이 됩니다. **"가장 강조되는 순간"** 이 가장 중요합니다. 그 순간이 곧 판정이 나오는 프레임이 됩니다.

### 10-2. 동작 → 기술로 바꾸는 판단 기준

| 질문                                         | 예 →                    | 이렇게 만든다                                    |
| -------------------------------------------- | ----------------------- | ------------------------------------------------ |
| 팔·다리가 **상대 쪽으로** 뻗나?              | 락킹 포인트, 크럼프 잽  | **근접 타격**. 뻗은 끝까지 판정                  |
| **아래로** 내리찍나? (스톰프, 힐 드롭)       | 크럼프 스톰프           | 바닥 근처 = **하단**, 위에서 내려오면 = **중단** |
| **위로** 올라가나? (팔·몸이 하늘로)          | 더기, 체스트 팝 어퍼    | **대공** (623 커맨드, 시작 무적)                 |
| **제자리에서** 몸을 쓰나? (웨이브, 팝, 포즈) | 팝핑 웨이브, 왁 포즈    | **장풍**(파동이 날아감) 또는 **몸 주변 충격파**  |
| **돌거나** 휘두르나? (트월, 윈드밀)          | 왁킹 트월               | **앞뒤 판정 다단**                               |
| **이동하는** 스텝인가?                       | 러닝맨, 스키터 래빗     | **돌진기** (236K 자리)                           |
| **바닥에서** 하나? (풋워크, 슬라이드)        | 비보이 식스스텝         | **하단 + 낮은 자세**(장풍 통과)                  |
| **뛰어오르나?**                              | 스쿠비 홉, 크리스크로스 | **중단** (뛰어서 내려오며 침)                    |
| **멈추는** 동작인가? (락, 프리즈, 포즈)      | 비보이 프리즈           | **반격 자세** 또는 **게이지 충전**               |
| 소품을 쓰나? (모자, 머리카락)                | 락킹 모자               | **도구 장풍** 또는 **과장 리치**                 |
| 상대와 **함께** 하는 동작?                   | 파트너 동작             | **잡기**                                         |

### 10-3. 어느 버튼에 넣을까 (자리 정하기)

| 자리              | 넣기 좋은 동작                                | 개수 |
| ----------------- | --------------------------------------------- | ---- |
| 약P / 약K         | 짧고 빠른 동작 (잽, 포인트, 탭)               | 각 1 |
| 강P / 강K         | 크고 강한 동작 (스윙, 큰 킥)                  | 각 1 |
| 앉아 4개          | 낮은 자세 동작 (바닥 치기, 스윕, 로우 스톰프) | 4    |
| 점프 약·강        | 공중 동작 (다이브, 공중 킥)                   | 2    |
| 6 + 버튼 (특수기) | 그 장르를 대표하는 **중거리** 동작 하나       | 1~2  |
| 236P / 236K       | 장르 **대표 기술** 2개 (장풍·돌진)            | 2    |
| 623               | 위로 올라가는 동작 (대공)                     | 1    |
| 214P / 214K       | 특이한 동작 (반격, 포즈, 중단 점프)           | 1~2  |
| 236236P           | 장르 기본기를 이어 붙인 **쇼케이스**          | 1    |
| 약P+약K           | 파트너 동작                                   | 1    |

> 자리가 꽉 차면 **기존 기술 하나를 바꿉니다.** 어떤 걸 뺄지는 같이 정해요 (장르 정확도가 낮은 것부터).

### 10-4. 넣는 과정 (제가 하는 일)

1. **양식 받기** → 10-2 기준으로 공격 종류·자리를 정해 **한 줄 요약으로 확인**받는다.
2. **키 포즈 3~5개** 를 코드로 만든다 (시작 → 강조 순간 → 끝). 강조 순간 = 판정 프레임.
3. 박자를 타이밍으로: "딱 멈춤"은 긴 정지 + 빠른 복귀, "빠른 연속"은 짧은 간격 다단.
4. 연습 모드에서 시범을 보고 **판정 박스(F1)** 와 동작이 맞는지 확인.
5. 동작 설명을 `scripts/spritegen/dance_moves.json`에 적고 **그림 생성** → 비교 시트로 검사 → 게임에 넣기.
6. 프레임 표(`FRAME_DATA.md`)를 다시 만들고 테스트를 통과시킨 뒤 커밋.

한 동작에 대략 그림 생성 5~10분 포함 **20~30분**이면 들어갑니다. 여러 개를 한꺼번에 주시면 그림은 한 번에 몰아서 만듭니다.

### 10-5. 예시: "크럼프 찢기"가 들어간 과정

| 단계                    | 내용                                                                                      |
| ----------------------- | ----------------------------------------------------------------------------------------- |
| 받은 말                 | "크럼프: 찢기"                                                                            |
| 해석 (확인 필요로 표시) | 가슴을 움켜쥐었다가 바깥으로 찢어 젖히는 크럼프 캐릭터 동작                               |
| 10-2 판정               | 제자리에서 몸을 쓰는 동작 + 강한 폭발 → **근거리 충격파, 가드 불가**, 느린 대신 강함      |
| 자리                    | 214P (기존 체스트 팝 자리)                                                                |
| 키 포즈                 | 웅크려 가슴 움켜쥠(10f) → 힘 모음(18f) → 두 팔 앞뒤로 찢어 젖힘(21f, 판정) → 끝(50f)      |
| 그림 설명               | "hunched over, both hands claw and grab the chest … then both arms rip outward and apart" |

**동작이 다르면 말로만 고쳐 주셔도 됩니다** ("찢기는 가슴이 아니라 팔을 찢는 거야" 등). 그 말로 키 포즈와 그림을 다시 만듭니다.
