# 장르별 동작 레퍼런스와 기술 재설계

> 목적: 각 장르의 **실제 기본기(이름 있는 동작)** 와 그 **정확한 몸 움직임**을 조사하고, 게임 기술을 그 기본기에서 만든다.
> 지금 기술 중 절반가량은 장르와 관계없는 일반적인 펀치·킥이다. 이 문서의 표가 새 기준이다.
> 각 기술은 **키 포즈 3~5개**(시작 → 타격 → 끝)로 적는다. 이 설명이 그대로 코드 포즈와 그림 생성 설명의 원본이 된다.

## 확정 구성 (2026-10-01 피드백)

아래 표가 장르별 각 절의 매핑보다 우선한다.

| -------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 크럼프   | 암 스윙 · 스톰프 · **찢기** · 점프 후 스톰프          | 강P 배트 스윙 / 6HP 피치 스윙(중단) / 약K 프론트 스톰프(하단) / 214P **찢기**(가슴을 움켜쥐었다 바깥으로 찢어 젖힘, 근거리 가드 불가) / 214K **점프 스톰프**(뛰어올라 내리찍고 바닥 충격파, 중단) / 점프 강 = 내리찍는 스톰프 |

## 읽는 법

- **기본기**: 그 장르에서 실제로 쓰는 이름과 움직임. 출처를 붙인다.
- **기술 매핑**: `게임 기술 ← 기본기`. 키 포즈는 오른쪽을 본다고 가정한다 (앞 = 상대 쪽).
- **신뢰도**: ●●● 여러 자료가 같은 설명 / ●● 이름과 대략의 설명 / ● 자료가 적어 해석이 들어감 (확인 필요)
- 판정 성질(상단·중단·하단, 장풍 등)은 [GAME_DESIGN.md](GAME_DESIGN.md) 규칙을 따른다.

## 공통 원칙

1. **모든 일반기·필살기는 그 장르의 기본기 하나에서 온다.** 출처가 없는 기술은 "게임 창작"으로 표시한다.
2. **그 기본기가 강조하는 순간 = 판정 프레임.** (크럼프 잽이 뻗는 순간, 락킹 포인트가 멈추는 순간, 팝핑 히트가 근육을 튕기는 순간)
3. **장르의 리듬감을 타이밍에 넣는다.** 락킹·팝핑은 "딱 멈춤"(긴 정지 후 빠른 복귀), 왁킹은 "빠른 연속", 크럼프는 "짧고 폭발적, 긴 여운", 하우스는 "멈추지 않는 발".
4. **대기 자세 = 그 장르의 기본 그루브.** (힙합 다운 바운스, 하우스 잭, 크럼프 벅 자세, 락킹 업락 자세 등)

## 1. 크럼프 KRUMP — 신뢰도 ●●●

**기원**: 2000년대 초 로스앤젤레스 사우스 센트럴. Ceasare "Tight Eyez" Willis, Jo'Artis "Big Mijo" Ratti, Marquisa "Miss Prissy" Gardner, Christopher "Lil' C" Toler. 1992년 Tommy the Clown의 **클라우닝**에서 나왔고, 클라우닝보다 "거칠고 날것"이라 갈라져 나왔다. 대부분 프리스타일, 배틀(세션) 중심.
**태도**: 공격적, 폭발적, "벅(buck)". 몸을 낮춘 채 상대에게 에너지를 던진다. **캐릭터**(야수·빙의 등)를 연기한다.

### 기본기

| 기본기                  | 정확한 움직임                                                                                                                       | 리듬                      |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| **스톰프** Stomp        | 무릎을 높이 들었다가 발을 바닥에 **때려 박고 다시 튕겨 올린다**. 바닥에서 에너지를 끌어 올리는 느낌. 잽·체스트 팝과 겹쳐 쓴다       | 비트·프레이즈 끝을 찍는다 |
| **잽** Jab              | 가슴에서 바깥으로 **짧고 날카롭게** 뻗었다가 강하게 당긴다. 팔꿈치는 느슨. 앞·몸 가로질러·머리 위 어느 방향이든                     | 스타카토                  |
| **체스트 팝** Chest pop | 숨을 크게 들이쉬듯 가슴을 **위·앞으로 터뜨린다**. 힘은 어깨가 아니라 몸통 중심에서. 느낌표처럼 짧게                                 | 강박                      |
| **암 스윙** Arm swing   | 중력을 실은 큰 휘두름. **작은 스윙 = 야구공 던지기(위에서 아래로)**, **큰 스윙 = 야구 배트 휘두르기(옆으로)**. 어깨에서 원을 그린다 | 다음 동작으로 이어 줌     |
| **벅 홉** Buck hop      | 무릎을 굽히고 상체를 웅크린 채 두 발로 힘차게 뛴다                                                                                  | 고조 구간                 |
| **킬 오프** Kill-off    | 배틀을 끝내는 결정타 연속. 상대를 "죽였다"는 뜻                                                                                     | 클라이맥스                |

## 2. 왁킹 WAACKING — 신뢰도 ●●●

**기원**: 1970년대 초 로스앤젤레스 게이 클럽의 **펑킹(punking)**. 이름은 Tyrone Proctor가 "움직이려면 팔을 '왁' 해야 한다"고 한 데서, Jeffrey Daniel이 정리. *Soul Train*으로 퍼졌다. 디스코(약 127~145BPM).
**태도**: 그레타 가르보·마를레네 디트리히 같은 옛 할리우드 여배우의 **포즈와 표정**. 감정 표현이 크다(보깅보다 덜 각지고 더 감정적).

### 기본기

| 기본기                     | 정확한 움직임                                                                                                                                                  | 리듬                       |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| **왁(휩)** Whack           | 팔을 어깨·팔꿈치에서 **채찍처럼 빠르게 휘둘러 딱 끊는다**. 한쪽으로 뻗었다가 휙 되돌려 몸과 날카로운 각을 만든다. 머리 위(오버헤드)·머리 아래(언더헤드)·앞으로 | 빠른 연속, 음 하나에 한 번 |
| **암 롤** Arm roll         | 어깨·팔꿈치·손목에서 시작한 원이 **머리 위를 지나 뒤로** 넘어간다. 쌍절곤에서 왔다                                                                             | 이어 줌                    |
| **라인** Lines             | 한 팔을 아래 → 옆 → 위 → 옆 → 아래로 **곧게** 뻗어 선을 그린다. 양팔 동시도                                                                                    | 박마다                     |
| **오버헤드** Overhead      | 쇄골 앞 손을 위로 올려 **목 뒤로** 넘긴다. 손이 뒤로 갈 때 가슴이 앞으로 나온다                                                                                |                            |
| **리스트 롤** Wrist roll   | 손목을 돌려 포즈와 포즈를 잇는다                                                                                                                               | 이음                       |
| **포즈** Pose              | 손가락 모양·시선·표정을 정해 **날카롭게 들어가 박자 동안 멈춘다**                                                                                              | 박 위에서 정지             |
| **헤어 브러시** Hair brush | 손으로 머리카락을 쓸어 넘긴다                                                                                                                                  |                            |
| **익스텐션** Extension     | 팔다리를 길게 뻗는 선                                                                                                                                          |                            |

## 7. 팝핑 POPPING — 신뢰도 ●●●

**기원**: 1975~77년 캘리포니아 프레즈노, Sam "Boogaloo Sam" Solomon과 **일렉트릭 부갈루스**. Popin' Pete 등. 펑크 음악, 박에 맞춘 근육 튕김.
**태도**: 기계·만화 같은 비현실감. 멈출 땐 완전히 멈춘다.

### 기본기

| 기본기                    | 정확한 움직임                                                                                |
| ------------------------- | -------------------------------------------------------------------------------------------- |
| **팝 / 히트**             | 근육을 **순간적으로 수축했다 풀어** 몸이 툭 튀게 한다. 팔·다리·가슴·목                       |
| **프레즈노 (슬롯)**       | 옆으로 디디며 **같은 쪽 팔과 다리를 번갈아 팝**, 끝은 단단한 포즈                            |
| **웨이브**                | 손끝에서 반대 손끝까지(또는 몸 전체로) 파도가 **관절을 하나씩 지나** 흐른다                  |
| **튜팅**                  | 팔과 손으로 **직각**(상자 모양)을 만든다. 이집트 벽화에서                                    |
| **로봇**                  | 팝을 여러 개 이어 기계처럼 움직인다                                                          |
| **애니메이션 / 스트로빙** | 스톱모션처럼 끊어 움직인다. **다임 스톱**(딱 멈추며 근육이 떨릴 정도의 히트)을 일정 간격으로 |
| **글라이드 / 플로팅**     | 바닥을 미끄러지는 착시 (백슬라이드 = 문워크)                                                 |
| **트위스트오플렉스**      | 몸의 부분들을 차례로 비틀어 관절이 이상하게 꺾인 착시. 비틀지 않는 부분은 완전히 정지        |
| **부갈루**                | 뼈가 없는 듯 엉덩이·가슴·어깨·무릎·머리를 원으로 굴린다                                      |
| **스케어크로**            | 줄에 매달린 인형처럼 히트                                                                    |

| ------------------------------ | ------------------- | -------------------------------------------------------------- | ---------- | --------------------- |

## 8. 브레이킹 BREAKING — 신뢰도 ●●●

## 9. 다음 작업

1. **이 문서 확인** — 특히 걸스힙합(신뢰도 ●)과 바꾸는 기술 이름. 실제 춤을 아시는 분의 의견이 가장 정확하다.

3. **그림 다시 만들기** — 키 포즈 표의 설명을 그대로 sprite-gen 설명에 넣는다 (`scripts/spritegen/build.py`가 프레임별 자동 설명 대신 이 표의 동작 설명을 쓰도록).
4. **대기 동작을 장르 그루브로** — 힙합 다운 바운스, 하우스 잭, 팝핑 프레즈노, 락킹 업 락 등.
