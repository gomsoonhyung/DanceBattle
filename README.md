# DANCE BATTLE

춤 동작으로 싸우는 2D 대전 격투 게임 (취미 프로젝트).
TypeScript + Vite + Canvas 2D. 그래픽은 코드로 그리는 스틱맨이다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 로직 테스트 (커맨드 인식, 타격/가드, 장풍, 아머 등)
npm run build      # 배포용 빌드 → dist/
```

- `http://localhost:5173/?gallery&char=krump`: 해당 캐릭터의 모든 동작을 반복 재생한다 (`bboy` / `krump` / `locker`)
- `http://localhost:5173/?gallery=stompWave&char=krump`: 해당 동작을 프레임별로 나열한다 (동작 id는 각 캐릭터의 `moves.ts` 참고)

## 조작

| | P1 | P2 |
|---|---|---|
| 이동 | W A S D | 방향키 |
| 약P / 강P | F / G | K / L |
| 약K / 강K | V / B | , / . |

게임패드: X 약P · Y 강P · A 약K · B 강K. 1번 패드는 P1, 2번 패드는 P2. 메뉴와 캐릭터 선택도 게임패드로 할 수 있다.

> 키보드 하나로 둘이 하면 키가 동시에 눌렸을 때 일부가 씹힐 수 있다(고스팅). 게임패드를 쓰면 가장 좋다.

**흐름**: 타이틀 → 캐릭터 선택(좌우로 고르고 약P 결정, 강P 취소) → 대전. 트레이닝 모드에서는 P1이 내 캐릭터와 연습 상대를 차례로 고른다. 대전이 끝나면 약P로 재대결, 강P로 캐릭터 다시 고르기.

**가드**: 뒤로 누르면 서서 가드, 뒤아래로 누르면 앉아 가드. 하단기는 앉아서만, 중단기(점프 공격 등)는 서서만 막을 수 있다.

**기타 키**: F1 판정 박스 보기 · ESC 메뉴 · (트레이닝) F2 연습 상대 행동 변경, R 위치 초기화

## 캐릭터

기본기는 셋 다 서서/앉아서 × 약P/강P/약K/강K와 점프 공격 2종이다. 약공격은 맞았을 때 필살기로 캔슬할 수 있고, 앉아 강P는 상대를 띄운다.
초필살기는 공통으로 그루브 게이지 MAX에서 **↓↘→↓↘→ + P** 또는 **강P+강K 동시**.

### B-BOY (브레이킹 · 올라운더) — 체력 1000

| 기술 | 커맨드 | 특징 |
|---|---|---|
| 헤드스핀 | →↓↘ + P | 대공기, 발동 직후 무적, 띄움 |
| 윈드밀 | ↓↘→ + P | 전진하며 4회 공격, **하단** |
| 에어플레어 | ↓↘→ + K | 빠르게 전진하며 2회 공격, 다운 |
| 프리즈 | ↓↙← + P | 반격 자세. 이때 맞으면 플립 킥으로 자동 반격 |
| 스와이프 킥 | ↓↙← + K | 뛰어들며 차기, **중단** |
| ★ 파워무브 콤보 | 초필살기 | 윈드밀 → 헤드스핀 연속기 |

콤보 예시: 앉아 약K → 앉아 약P → 윈드밀 / 앉아 강P(띄움) → 헤드스핀

### KRUMPER (크럼프 · 파워형) — 체력 1100

| 기술 | 커맨드 | 특징 |
|---|---|---|
| 버스트 어퍼 | →↓↘ + P | 대공기, 발동 직후 무적, 높은 데미지 |
| 스톰프 웨이브 | ↓↘→ + P | 바닥을 타고 가는 충격파 장풍, **하단** |
| 버스트 러시 | ↓↘→ + K | **슈퍼아머** 돌진 (한 번은 맞아도 멈추지 않음) |
| 체스트 팝 | ↓↙← + P | **가드 불가**. 발동이 느려서 보고 점프로 피할 수 있다 |
| ★ 킬 오프 | 초필살기 | 암 스윙 연타 → 스톰프 마무리 |

### LOCKER (락킹 · 스피드형) — 체력 950

| 기술 | 커맨드 | 특징 |
|---|---|---|
| 점프 락 | →↓↘ + P | 대공기, 발동 직후 무적 |
| 엉클 샘 포인트 | ↓↘→ + P | 빠른 포인트 장풍. 높게 날아가서 **앉으면 피할 수 있다** |
| 스쿠비 두 러시 | ↓↘→ + K | 빠르게 달려들어 2회 공격, 다운 |
| 리스트 트월 | ↓↙← + P | 근거리 4연타 |
| 니 드롭 | ↓↙← + K | 뛰어올라 무릎으로 내려찍기, **중단** |
| ★ 락 앤 포인트 | 초필살기 | 러시 연타 → 긴 포인트 마무리 |

서서 강K(하이 킥 락)는 높게 차서 앉은 상대에게는 맞지 않는다.

## 구조

```
src/
├── core/           고정 60fps 상수, 수학 유틸
├── input/          키보드/게임패드 입력, 프레임 단위 입력 버퍼 (커맨드 인식), 메뉴 입력
├── anim/pose.ts    스틱맨 뼈대, 포즈 키프레임 보간
├── fighter/        캐릭터 상태 머신, 기술/캐릭터 데이터 형식(types.ts)
├── characters/
│   ├── index.ts    캐릭터 목록, 기술표 생성
│   ├── common.ts   공통 동작 (점프, 피격, 가드, 다운, 기상)
│   ├── bboy/       비보이
│   ├── krump/      크럼프
│   └── locking/    락킹
├── game/           대전 진행(match.ts), 타격·장풍 판정(combat.ts)
├── screens/        캐릭터 선택 화면
├── render/         화면 그리기 (무대, 스틱맨, HUD, 이펙트, 장풍)
├── audio/          합성 효과음
└── debug/          동작 갤러리
```

설계 원칙:
- **게임 로직(`game/`, `fighter/`)은 렌더링과 분리되어 있다.** 나중에 2.5D/3D로 바꿔도 `render/`만 교체하면 된다.
- **로직은 결정론적이다.** 같은 입력이면 항상 같은 결과가 나온다(테스트로 확인). 나중에 온라인 롤백 넷코드를 붙일 때 필요하다.
- **기술은 데이터다.** `moves.ts`에서 프레임, 히트박스, 데미지를 고치면 바로 반영된다. F1로 판정 박스를 보면서 조정하면 편하다.

## 캐릭터/기술 추가하기

- **기술 추가**: 캐릭터 폴더의 `moves.ts`에 `MoveDef`를 만들어 목록에 넣는다. 커맨드 기술이면 `index.ts`의 `specials`에도 등록한다. 장풍은 `projectile`, 슈퍼아머는 `armor`, 가드 불가는 히트의 `unblockable`로 지정한다.
- **캐릭터 추가**: `krump/`처럼 폴더를 만들고 `poses.ts`(기본 자세, 대기/걷기/앉기/승리 동작), `moves.ts`, `index.ts`(외형, 스탯, 커맨드)를 작성한 뒤 `characters/index.ts`의 `CHARACTERS`에 넣는다. 피격·점프 같은 공통 동작은 `baseAnims(서기, 앉기)`가 자동으로 만들어 준다.

포즈 각도 규칙은 `src/anim/pose.ts` 맨 위 주석을 참고한다. 지면 스냅이 기본으로 켜져 있어서, 포즈를 만들 때 몸의 높이는 신경 쓰지 않아도 된다(가장 낮은 부위가 자동으로 바닥에 닿는다).
