**강P 6장은 다시 만들어 주세요.** 보폭과 팔 뻗기가 참고 그림보다 넓어서 공격 판정과 어긋납니다.

## 잘 된 점

- **일관성**: 14장 모두 얼굴, 옷, 색, 비율이 같습니다. 가장 어려운 부분인데 잘 지켜졌습니다.
- **규격**: 640×640, 투명 배경, 90~116KB, 발밑 위치 모두 정확합니다 (`check_sprites.py` ❌ 없음).
- **대기**: 참고 그림과 거의 정확히 겹칩니다 (앞쪽 끝 차이 1~11px).
- **강P 흐름**: 예비 동작 → 휘두르기 → 따라 휘두르기가 또렷하게 읽힙니다.

## 고쳐야 할 점

### 1. 강P가 참고 그림보다 멀리 뻗음 (다시 만들기)

| 프레임               | 앞쪽 끝 차이 |
| -------------------- | ------------ |
| `sHP_0`              | +27px        |
| `sHP_4`              | +32px        |
| `sHP_7`              | +45px        |
| `sHP_11` (공격 판정) | **+40px**    |
| `sHP_15`             | +44px        |

`sHP_11`의 주먹이 판정 범위 끝보다 약 20(게임 좌표)만큼 더 나가 있어서, 주먹이 닿아 보이는데 안 맞는 상황이 생깁니다.
보폭(앞발·뒷발 사이)도 참고 그림보다 넓습니다. `fit_sprite.py`가 키에 맞춰 크기를 조절하기 때문에, 자세가 넓으면 그만큼 앞뒤로 삐져나옵니다.

- 다시 생성할 때 **참고 그림의 실루엣 폭 안에** 들어오도록 요청해 주세요 (보폭을 좁게, 팔을 덜 뻗게).
- `check_sprites.py`에 **앞쪽 끝 비교(±20px)** 를 추가했습니다. 이제 이런 차이는 ⚠️로 바로 보입니다. **강P는 ⚠️가 없을 때까지** 고쳐 주세요.

### 2. 머리띠가 눈을 가림

머리띠가 눈높이에 있어서 안대처럼 보입니다. 원인은 참고 그림입니다 (코드 그림에서 머리띠가 눈높이에 있었음). **참고 그림을 고쳤으니** (`docs/design/reference/krump/` 갱신) 머리띠를 **이마, 눈썹 위**로 올려 주세요.

- `docs/design/krump_sheet.png` 설정 그림도 머리띠 위치를 고쳐 주세요.
- 대기 8장은 지금 그대로 써도 되지만, 설정 그림을 고친 뒤에는 대기도 다시 만들어 맞추는 게 좋습니다.

### 3. 확인 방법 바로잡기

- **갤러리(`?gallery=...`)는 교체 그림을 보여 주지 않습니다.** 항상 코드 그림을 그립니다. 교체 그림은 **실제 게임**에서 확인하세요: 트레이닝 → 크럼프 선택 → 대기 모습 / 강P(G키).
- `npm run smoke`나 `shots`가 통과해도 교체 그림이 나왔다는 뜻은 아닙니다.

## 개발 쪽에서 고친 것 (참고)

- **대기 그림이 첫 반복 이후 사라지던 버그**를 고쳤습니다. 반복 동작의 그림 번호가 한 바퀴를 넘으면 목록에서 찾지 못했습니다. 이제 계속 그림으로 나옵니다.
- **P2 표시**: P2 전용 그림(`_p2`)이 없으면 전에는 색상을 통째로 돌려서 피부까지 청록색이 됐습니다. 이제는 P1 그림 그대로에 **P2 색 테두리 빛**만 둘러 구분합니다. 제대로 된 P2 색은 `_p2` 그림이 필요합니다.
- **머리띠 위치**: 참고 그림의 머리띠를 이마로 올렸습니다.
